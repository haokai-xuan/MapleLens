# MapleLens

**MapleLens** is a mobile app designed to help users find Canadian alternatives for American products. By simply taking a photo of an American product, users can instantly receive a list of similar Canadian products, making it easier to support local businesses and make informed purchasing decisions.

## Features

- **Capture Product Photos:** Take a photo of an American product using the in-app camera.
- **Instant Canadian Alternatives:** Receive a list of Canadian alternatives based on the product image.
- **Google Vision Integration:** Utilize Google Vision API for accurate image recognition and analysis.
- **Simple Interface:** A user-friendly interface with a clean and intuitive design for an optimal experience.

## Technologies

- **Flutter:** A cross-platform framework for building the mobile app.
- **Google Vision API:** For image recognition and identifying products.
- **Firebase (Optional):** Can be used for backend services, such as user authentication and storing product data.
